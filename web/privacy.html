Ghost Text

Privacy

Short version: we keep no pages, no screenshots, no URLs and no hidden text. We keep a count of scans per day, with no content in it.

Scanning a page on this site

You send a URL or pasted HTML. A browser opens the page, either on this server or in a Browserbase cloud browser if this instance uses one. The hidden text found on the page goes to the AI judge, an open-weight model. It runs on this server or at a hosted model provider such as Groq, depending on how this instance is set up. You get the result back, and the server then forgets the page, the screenshot and the text.

Ghost Text Shield (the Chrome extension)

The shield checks pages inside your browser. When its rules can't decide on a hidden sentence (six words or more, or text in a script without spaces such as Chinese), it sends that sentence to the judge. It never sends the page or its URL. You can switch the judge off in the shield's popup, and then nothing leaves your browser.

Search check and AI summaries

A search check sends your query to SerpApi and scans the top results. The result list is reused for an hour, so the same search doesn't cost twice, and stays in this server's memory (never on disk) until it restarts. An AI summary sends the page text to the summary model, and the two summaries stay in memory until the server restarts or newer ones push them out. Both features need you to sign in, which Auth0 handles. We only see the account ID Auth0 gives us.

What we keep

For each request we write one line: the day, which feature was used, the verdict, how long it took, and how many judge calls failed. We never write the URL, the page, the hidden text, your IP address or your account. You can see the totals at /stats.

To enforce rate limits, the server holds your IP address in memory. It is never written to disk and is gone when the server restarts.

Training

We do not train models on what you scan.

Run it yourself

Ghost Text is open source. If a page must never leave your machine, run the scanner locally: python -m scanner.cli <url> --clean.
