        Install the shield

        It isn't in the Chrome Web Store yet, so it installs in four steps. Works in Chrome, Edge, Brave, Arc and other Chromium browsers.

        1. Download the shield and unzip it.
        2. Open chrome://extensions in a new tab.
        3. Turn on Developer mode (top right).
        4. Click Load unpacked and choose the unzipped folder. Pin the ghost to your toolbar.

        What it covers: assistants that read the tab you have open, such as browser side panels and AI browsers. What it can't cover: assistants that fetch a page on their own servers. For those, check the page here first, or use the API.

        Privacy: the shield works inside your browser. Only hidden sentences it can't decide on are sent to the Ghost Text judge, never the page, and you can turn that off in the popup.

        How it works

        1. Load it like a browser

          The page opens in a real Chromium browser, scripts and all, so we see what an AI agent sees.

        2. Compare two readings

          For every piece of text we ask: can a person see this? Does an AI get it? Text only the AI gets is a ghost.

        3. Judge each ghost

          Rules and a small open model label each ghost harmless, worth a look, or an attack. Code, not the model, sets the verdict.

        Use it from code

        Building an agent or a RAG pipeline? Send pages through Ghost Text first and give your model clean_text: the page with the attacks taken out.

        curl -X POST https://ghosttext.example/scan \
  -H "Content-Type: application/json" \
  -d '{"url": "https://example.com/product"}'

        Or run it on your own machine, so pages never leave it:

        python -m scanner.cli https://example.com/product --clean
