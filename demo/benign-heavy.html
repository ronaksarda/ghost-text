Getting started

Lantern is a small command-line tool for checking links in static sites. Install it, point it at a folder, read the report.

EmpezarErste Schritte

Install

brew install lantern
curl -fsSL get.lantern.sh | sh
winget install lantern

Run it

lantern check ./public

The report lists every broken link with the file and line it came from.

FAQ

Does it follow external links?

Only with the --external flag. It waits one second between requests.

Can I ignore some paths?

Yes. Put one glob per line in a .lanternignore file.

Does it work offline?

Internal links are checked offline. External ones need a network.
